# Contributing to DictaType

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Keep student data local and avoid adding mandatory cloud services, telemetry or advertising.
3. Add or update tests for scoring and database changes.
4. Run `python -m unittest discover -s tests -v` before opening a pull request.
5. Explain the classroom use case and any privacy implications in the pull request.

Use clear names, type hints and small functions. User-facing text should remain accessible to non-technical teachers and students.
