DictaType French installer compatibility fix
============================================

Replace ONLY this file in your GitHub repository:

  installer.iss

Do not replace the workflow for this fix.

Why this fixes the current failure
----------------------------------
Your current GitHub workflow downloads Piper's original files:
  assets/voices/fr_FR-siwis-medium.onnx
  assets/voices/fr_FR-siwis-medium.onnx.json

The previous installer expected the renamed files:
  assets/voices/french.onnx
  assets/voices/french.onnx.json

This installer accepts EITHER naming scheme automatically. At install time it
always writes the stable runtime names:
  {app}/voices/french.onnx
  {app}/voices/french.onnx.json

Steps
-----
1. Upload the installer.iss from this ZIP to the repository root, replacing the existing file.
2. Commit the change.
3. GitHub -> Actions -> Build Windows release -> Run workflow.
4. Download the DictaType-Windows artifact after the build succeeds.
5. Install DictaType-Setup.exe.
6. Open Teacher -> Settings & Security and test the French neural voice.

If the build fails again, send the first error line plus the name of the failed GitHub Actions step.
