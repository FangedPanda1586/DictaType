DictaType French Neural Voice - External Runtime Fix
=================================================

WHY THIS FIX
------------
The French ONNX model is now installed beside DictaType.exe instead of being
embedded inside the PyInstaller one-file payload. This is more reliable and is
also faster on 4 GB RAM / HDD classroom PCs because the ~60 MB voice model does
not need to be extracted to a temporary directory every time DictaType starts.

IMPORTANT
---------
Keep dictatype.ico at the repository root.

After the GitHub build, the portable ZIP must contain:
  DictaType/DictaType.exe
  DictaType/voices/fr_FR-siwis-medium.onnx
  DictaType/voices/fr_FR-siwis-medium.onnx.json

The installer places the same two voice files in:
  <DictaType install folder>/voices/

The GitHub workflow synthesizes a real French sentence using the FINISHED EXE
and the staged external voice directory. If that test fails, the release stops.

After installation:
Teacher -> Settings & Security -> Test French neural voice
should audibly speak a French test sentence.
