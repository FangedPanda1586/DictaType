DictaType French Voice + Adaptive Performance Update
=====================================================

This is a cumulative patch. You do NOT need to install the French-voice fix and
low-end optimization separately.

It combines:
- verified built-in fr-FR Piper neural voice packaging
- finished-EXE French synthesis verification in GitHub Actions
- automatic low-memory/HDD optimization for 4 GB classroom PCs
- pre-generated and disk-cached exam/classroom audio
- neural model release before students join exams
- exam/classroom mode, multi-passage exams and combined exam PDF reporting
- PIN-free student profiles and student history support from the recent updates

IMPORTANT
---------
Keep dictatype.ico at the repository root. DictaType.spec uses:
  icon="dictatype.ico"

Do not delete or reset the existing DictaType database.

GITHUB BUILD CHECK
------------------
After uploading the files, run:
  GitHub -> Actions -> Build Windows release -> Run workflow

The workflow should include these steps:
  1. Download built-in French neural voice
  2. Build portable executable
  3. Verify French neural voice inside built EXE

The third step launches the FINISHED DictaType.exe and synthesizes an actual
French WAV. If the neural model/runtime is missing, the workflow fails instead
of publishing a broken installer.

PERFORMANCE BEHAVIOUR
---------------------
Automatic is recommended.

Automatic selects Low-memory/HDD mode when the machine has:
- 6 GB RAM or less, or
- 2 logical CPUs or less

Low-memory/HDD mode includes:
- lazy loading of Piper/ONNX only when French audio is needed
- pre-generation of exam/classroom audio before students join
- WAV caching on disk instead of keeping audio in RAM
- release of the French neural model after audio preparation
- streaming audio to student browsers in small chunks
- browser caching of session audio for replays
- conservative CPU-thread hints for neural synthesis
- reduced UI redraw/hover work
- smaller recent-results classroom view
- HDD-friendly SQLite settings

Every Exam pre-generates audio before the exam server opens, even on faster PCs.

EXPECTED SETTINGS STATUS
------------------------
After a successful Windows build, Teacher -> Settings & Security should show:
  Built-in French neural voice ready

and Windows/system voices are listed separately from the neural voice.
