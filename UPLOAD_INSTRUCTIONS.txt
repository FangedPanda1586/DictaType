DictaType - Python 3.12 winsound compatibility fix
==================================================

Problem fixed
-------------
The Windows build uses Python 3.12. winsound.SND_SYNC was added only in
Python 3.14, so neural voice playback raised:

    module 'winsound' has no attribute 'SND_SYNC'

Python 3.12 already plays PlaySound synchronously by default. This patch uses
SND_FILENAME plus SND_SYNC only when the running Python version provides it.

Replace these files in the repository
-------------------------------------
1. dictatype/tts.py
2. tests/test_winsound_compatibility.py

Do NOT replace the v7 ONEDIR workflow, DictaType.spec, or installer.iss.

Then commit and start a NEW GitHub Actions run.
