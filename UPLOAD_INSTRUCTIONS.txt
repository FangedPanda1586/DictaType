DictaType deterministic French neural voice build fix
=====================================================

Replace BOTH of these files in the same GitHub commit:

1. installer.iss
2. .github/workflows/windows-build.yml

Do not replace only one of them. They are intentionally paired.

Then:
1. Commit the changes.
2. Open GitHub -> Actions -> Build Windows release.
3. Click Run workflow.

The workflow now downloads the French model AFTER PyInstaller has finished,
directly into dist\voices. The installer uses those exact same files.

Expected successful order:
- Build portable executable
- Download French neural voice into release folder
- Verify French neural voice inside built EXE
- Verify installer inputs
- Build Windows installer
- Verify installer was created

The installer and portable ZIP both use:
  voices\french.onnx
  voices\french.onnx.json
