DictaType French neural path fix
================================

Replace these files in your GitHub repository using the files from this package.
Do NOT copy their contents from formatted chat text. Upload the actual files.

1. dictatype/tts.py
2. installer.iss
3. .github/workflows/windows-build.yml
4. tests/test_french_release_filename.py   (new file)

The fix deliberately uses simple release filenames with no underscores:

assets/voices/french.onnx
assets/voices/french.onnx.json
installer-output/DictaType-Setup.exe

The Piper downloader may still download its original fr_FR-siwis-medium files,
but the workflow immediately copies them to the simple filenames above. DictaType
and the installer use only the simple release filenames.

After committing, run:
GitHub -> Actions -> Build Windows release -> Run workflow

Before Inno Setup, confirm the log has:
- Download built-in French neural voice: success
- Verify French neural voice inside built EXE: success
- Verify installer French voice sources: success

The Inno Setup [Files] lines should mention:
assets\voices\french.onnx
assets\voices\french.onnx.json

The Inno output directory should be:
installer-output
