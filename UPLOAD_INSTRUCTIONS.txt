DictaType built-in French neural voice update
=============================================

This update adds an offline fr-FR neural voice using Piper and the
fr_FR-siwis-medium voice model.

Replace these files in your GitHub repository:
  dictatype/tts.py
  dictatype/classroom.py
  dictatype/ui.py
  requirements.txt
  pyproject.toml
  DictaType.spec
  .github/workflows/windows-build.yml

Add these files:
  tests/test_french_voice.py
  assets/voices/NOTICE.txt

IMPORTANT
---------
Do NOT manually download or upload the ~63 MB voice model to GitHub.
The updated GitHub Actions workflow downloads it automatically during the
Windows build and PyInstaller embeds it into DictaType.exe.

The DictaType.spec in this update uses:
  icon="dictatype.ico"
which matches the root-icon layout that previously fixed your Windows build.
If your repository has moved the icon elsewhere since then, adjust that one
line before running the workflow.

Build:
  GitHub -> Actions -> Build Windows release -> Run workflow

Expected new workflow step:
  Download built-in French neural voice

After installation:
  - New French dictations show "DictaType French Neural" in the Voice list.
  - Classroom/Exam has "Use DictaType built-in French neural voice" enabled.
  - French audio is generated locally by the teacher computer and sent as WAV.
  - Students do not need a French Windows voice or internet connection.
  - If neural synthesis fails, DictaType retains its Windows/browser fallback.
