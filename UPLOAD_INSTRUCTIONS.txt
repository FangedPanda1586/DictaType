DictaType 1.0.0-rc.1 PUBLIC RELEASE PATCH
==========================================

This patch is designed to be applied on top of the current v7 ONEDIR build plus the Python 3.12 winsound compatibility fix.

or any other current project files.

BUILD / TEST
------------
1. Commit all public-release patch files together.
2. Open GitHub Actions.
3. Run: Build Windows public release - DictaType v1.0 RC1
4. Confirm the automated tests pass.
5. Confirm both Piper checks pass:
   - Verify Piper with normal Python before frozen test
   - Verify French neural voice inside finished EXE
6. Download the DictaType-Windows artifact.
7. Install DictaType-Setup.exe on a clean Windows PC.
8. Test Preview Voice with a multi-sentence passage. It should read the whole passage.
9. Test About DictaType from the login screen.
10. Test French neural voice, backup/restore, Classroom, Exam, and PDF export.

PUBLIC PRE-RELEASE
------------------
Only after the clean-PC checks pass, create the tag:

v1.0.0-rc.1

The workflow will publish a GitHub pre-release with generated release notes.

IMPORTANT
---------
RC1 may still be unsigned. Windows can display an unknown-publisher / reputation warning until code signing is configured.
