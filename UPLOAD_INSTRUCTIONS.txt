DictaType RC1 - French local exercise + Settings scroll fix
==========================================================

Replace/add ONLY these files in the repository:

1. dictatype/ui.py
2. tests/test_french_local_and_settings_scroll.py
3. CHANGELOG.md

Do NOT replace the current public RC1 GitHub Actions workflow, DictaType.spec,
installer.iss, or dictatype/tts.py with older copies.

After committing the three files above, start a NEW GitHub Actions run.

What this patch changes
-----------------------
- French local/student exercises automatically use the bundled DictaType
  French neural voice when the model is available, even if an older lesson
  was saved with a Windows/SAPI French voice.
- Existing French dictations open with the bundled neural voice selected in
  the editor, so Preview Voice and newly saved settings are consistent.
- Settings & Security is vertically scrollable and supports the mouse wheel,
  keeping backup, voice, About/licensing and other controls reachable on
  smaller screens.

Quick checks after installing the new build
-------------------------------------------
1. Open an OLD French dictation that previously used the Windows voice.
2. Start it from the student exercise screen. It should use DictaType French Neural.
3. Edit that same French dictation. Voice should show DictaType French Neural.
4. Open Settings & Security on a small window and scroll to the bottom.
